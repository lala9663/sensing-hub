# 이슈

메뉴 **이슈** (`#/issues`). 같은 사건을 다룬 여러 언론사 기사를 한 묶음(이슈)으로 보여 줍니다. 권한은 VIEWER 이상입니다.

## 이 탭에서 하는 일

- **기간** 칩(마지막 기사 기준 오늘·3일·7일, 기본 3일)과 **언론사 수** 칩(2곳+ / 3곳+ / 5곳+, 기본 2곳+)으로 많이 보도된 이슈만 남기고,
  검색어로 찾습니다.
- 카드마다 대표 제목·언론사 N곳·기사 M건·기간·핵심 낱말이 보이고, 펼치면 소속 기사가 나옵니다. 72시간 동안 새 기사가 없어 닫힌 이슈에는
  "지난 이슈" 표시가 붙습니다. 이슈 하나를 펼친 채로 보려면 `#/issues/{id}`.
- 문서 화면의 "이슈 #id (N건)" 링크와 챗봇 답의 근거(이슈)도 이 화면으로 옵니다. 챗봇에 "오늘 많이 보도된 이슈 알려 줘"라고 물으면
  같은 목록(`list_issues`)으로 답합니다.

## 어떻게 동작하나

- 워커가 문서를 전문 검색 색인한 직후([02-documents.md](02-documents.md)) 같은 트랜잭션에서 문서마다 이슈를 정합니다. 임베딩 없이 **제목 낱말 겹침**으로,
  결정적으로 묶습니다.
  - 제목 낱말([단독]·(종합)·연재명·흔한 낱말은 뺀다)이 최근 **72시간** 안의 이슈의 핵심 낱말(소속 기사 제목에 많이 나온 15개)과 충분히 겹치면 그 이슈에 붙이고,
    아니면 새 이슈를 만듭니다. 기준: 겹침 계수 0.4 이상, 겹친 낱말 2개 이상, 2개뿐이면 0.66 이상.
  - 72시간 동안 새 기사가 없는 이슈는 닫혀 더는 비교하지 않습니다. 72시간은 수집 시각이 아니라 **발행 시각** 기준이라, 과거 기사 채우기로 들어온
    석 달 전 기사는 그 무렵의 이슈와만 비교됩니다.
  - 예: "할리스 개인정보 유출"을 쓴 언론사 10곳의 기사 11건이 이슈 하나("언론사 10곳 · 기사 11건")로 보입니다.
- 목록은 언론사 수 → 기사 수 순입니다(`issue`·`issue_document`, V11).
- 기준값은 운영 DB 제목 2,998건(53개 언론사)으로 보정했습니다 → 언론사 2곳 이상 이슈 287개, 3곳 이상 122개, 5곳 이상 47개.
  원리는 [../how-collection-works.md](../how-collection-works.md)의 "수집 뒤: 인덱싱과 이슈 묶기", 이유는 [../decisions.md](../decisions.md).

## 설정

| 변수 (워커) | 기본값 | 설명 |
| --- | --- | --- |
| `SENSING_INDEX_ENABLED` / `SENSING_INDEX_BATCH` | `true` / `200` | 색인과 이슈 묶기를 함께 켠다. 큐가 빌 때마다 한 묶음씩 (LLM 설정과 무관) |
| `SENSING_ISSUE_WINDOW_HOURS` | `72` | 이 시간 안의 이슈와만 비교하고, 마지막 기사가 이보다 오래된 이슈는 닫는다 |
| `SENSING_ISSUE_THRESHOLD` / `SENSING_ISSUE_MIN_SHARED` / `SENSING_ISSUE_PAIR_THRESHOLD` | `0.4` / `2` / `0.66` | 붙이는 기준: 제목 낱말과 이슈 서명의 겹침 계수, 겹친 낱말 수, 2개만 겹쳤을 때의 겹침 계수 |

이미 쌓인 문서를 한 번에 색인·묶으려면 `sensing-index-backfill [--limit N]` ([02-documents.md](02-documents.md#설정)).

## API

```bash
# 이슈 목록 (언론사 수 → 기사 수 순). since·min_docs·min_sources·q·limit
curl 'http://127.0.0.1:8080/api/v1/issues?since=2026-10-18T00:00:00Z&min_sources=3' -H 'X-User: viewer'
# 이슈 상세 (소속 기사)
curl http://127.0.0.1:8080/api/v1/issues/1 -H 'X-User: viewer'
```

## 한계와 주의

- 제목 낱말이 겹쳐야 묶이므로, 같은 사건이라도 제목 표현이 크게 다르면 다른 이슈로 나뉩니다. 반대로 흔한 낱말이 두세 개 겹친 다른 사건이
  붙는 일을 막으려고 기준을 보수적으로 잡았습니다.
- 언론 기사는 본문을 저장하지 않으므로 묶는 근거는 제목뿐입니다.
- 색인 전 문서(유휴 틱마다 200건씩 처리)는 아직 이슈가 없습니다.
